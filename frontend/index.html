✦ Pipeline

How it Works

01
📷

Image Upload

Your image is sent to the local FastAPI backend. Nothing leaves your machine except the Gemini API call (if enabled).

→
02
✦

Gemini Vision

The full image is analyzed by Google Gemini — identifying every produce type and scoring freshness holistically in one pass.

→
03
🎯

Local Fallback

If Gemini is unavailable, YOLOv8 detects items and CLIP scores each crop against fresh vs. rotten prompts — fully offline.

→
04
📊

Grade Report

Scores are mapped to a /10 scale with Fresh, Use Soon, or Discard labels and a detailed note for each item.
